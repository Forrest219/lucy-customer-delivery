# Lucy 2.0.0 r6 升级验证候选

2026-10-21。当前为 Draft 候选，原生 amd64 升级、首次管理员、业务连续性及完整恢复验收尚未完成。当前正式版仍为 20261009-v1。

## 本次批次变化

r5 在上传前逐层检查时发现带入了本机生成的嵌套运行状态文件，因此原 r5 未上传。r6 增加构建上下文排除规则，隔离任意深度的 `.ktx`、`.ktx-ui`、`:memory:`、客户端 `.mcp.json`、本地环境文件和 WebUI 私有账号/权限配置，并补充实际 Docker 构建上下文回归。保留原包不变，新批次使用独立镜像、源码提交和摘要。

## 相对上次正式版的用户变化

- 首次管理员登录与供应方配套引导密钥；客户先执行检查，再部署并创建首个所有者。同实例重出包/升级/重试复用原密钥，另一实例分别签发。
- 软件包出包时同步生成/复用私有附件并检查软件包绑定。公开仓库不包含私有附件。
- 新增版本信息页，可核对产品版本、构建提交和 KTX 版本；账户菜单集中系统手册和退出登录。
- 问询预算检查覆盖本地工具；达到预算可能返回 `question_budget_exhausted`。
- 修正中文 Wiki 关键词补查、调用流水关联字段写入及缺失 suite hash 的评测结果导入。
- 保留单副本、Recreate、旧 PVC、端口、配置和 Secret；升级包含停机备份，不承诺零停机。

## 验证边界

已完成本机验证：隔离回归 7 项、部署 Python 回归 22 项、Node 凭据/封包回归 39 项，均通过；镜像 G1/G2/G3/G4/G4b/G4c/G4d/G8、Helm 静态检查、K6 导出/重导入与最终归档 HTTP/HTTPS 部署入口预检通过。C20 同包附件检查通过，同实例密钥复用，私有附件未上传。
